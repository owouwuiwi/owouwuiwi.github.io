# Original demo assets

All images, sample story text, subtitles and video were created specifically for this example. No scans, anime clips, characters, music or third-party publisher data are used.

The generated media and sample text are dedicated to the public domain under CC0-1.0: https://creativecommons.org/publicdomain/zero/1.0/

The generator and extension code use Apache-2.0. FFmpeg is a local generation tool; its binary is not distributed in this kit or website. The hashes of generated media are in assets-manifest.json. The TV test file is finite; it is not advertised as a real live broadcast.
